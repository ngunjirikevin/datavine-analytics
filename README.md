# Machine Learning Summative Lab

## Overview

This project explores three machine learning applications using classification, recommendation systems, dimensionality reduction, and clustering techniques.

The project consists of three analyses:

1. **Wine Classification** – K-Nearest Neighbors (KNN) with PCA and hyperparameter tuning.
2. **Agricultural Feed Recommendation** – PCA and cosine similarity for recommending feeds with similar performance profiles.
3. **Regional Crime Pattern Analysis** – K-Means and Gaussian Mixture Models (GMM) for identifying patterns in U.S. crime data.
